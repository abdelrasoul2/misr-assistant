# 🇪🇬 Misr Assistant

> Smart Government Assistant — منصة تبسيط وتجميع وتنظيم المعلومات الحكومية الرسمية للمواطن المصري.

## ما هو؟

المستخدم لا يحتاج معرفة الاسم الرسمي للخدمة. يكتب:

> "بطاقتي ضاعت وعايز أطلع واحدة جديدة"

والنظام يفهم أن المقصود: **بدل فاقد بطاقة الرقم القومي**.

## المبدأ الأساسي

- لسنا جهة حكومية.
- لا نعطي معلومة باعتبارها قانوناً نهائياً.
- كل معلومة لها مصدر رسمي + تاريخ تحقق + حالة تحقق.

## هيكل المشروع

| المجلد | الوصف |
|---|---|
| `backend/` | API + Business Logic |
| `frontend/` | الموقع العام (PWA) |
| `admin/` | لوحة تحكم المسؤولين |
| `docs/` | التوثيق الفني والمنتج |
| `scripts/` | سكربتات التطوير والنشر |
| `tests/` | اختبارات تكاملية |
| `infra/` | إعدادات النشر والبنية التحتية |
| `.cache/` | كاش pip و npm (على D:) |
| `logs/` | سجلات التطوير |
| `.backups/` | نسخ احتياطية محلية |
