# Backend - Misr Assistant API

FastAPI-based backend.

## Stack
- Python 3.12+
- FastAPI
- SQLAlchemy 2.x
- Alembic
- Pydantic v2

## Development

    python -m venv .venv
    .\.venv\Scripts\Activate.ps1
    pip install -r requirements.txt
    uvicorn app.main:app --reload

Docs: http://127.0.0.1:8000/docs
