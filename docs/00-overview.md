# 00 — Overview

## الرؤية

> "مساعد يفهم ماذا تريد ويخبرك ماذا تفعل."

## المشكلة

المواطن المصري لا يعرف:
- المستندات المطلوبة
- الخطوات
- الرسوم
- مكان تقديم الخدمة
- المدة المتوقعة
- الرابط الرسمي

## الحل

منصة تجمع المعلومات الرسمية وتبسطها، وتفهم اللغة الطبيعية واللهجة المصرية.

## قواعد صارمة

1. لا نخترع معلومات حكومية.
2. كل معلومة لها مصدر رسمي.
3. كل معلومة لها تاريخ تحقق.
4. كل معلومة لها حالة: Verified / Needs Review / Outdated.
5. لا نستخدم Blogs كمصادر أساسية.
